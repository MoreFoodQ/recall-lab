## 1. 阻擋項（上線前應修）

### B1. 未完成的練習會被無聲覆蓋（非預期的資料遺失）
`start()`（app.js:29）每次呼叫都直接執行 `state.session = session`。只有「隨機測驗」頁有一句提示，其他入口都不會詢問：
- 題庫列表點任一題（`data-open` → `start('all','all',id)`）：例如做到第 57/100 題時，回題庫看一題，整個練習就被換成只有 1 題的新練習。
- 總覽的「開始完整練習」、「今天怎麼練」卡片，以及題庫、錯題、收藏頁的「練習這 N 題」。

答題紀錄（`history`）會保留，但練習的順序、選項排列和本輪的作答都會消失，而且無法復原。
**建議**：當 `session` 存在、尚未結束、且已作答 ≥1 題時，先用 `<dialog>` 確認「取代未完成的練習？」。題庫點單題時，最好改成「單題預覽」，不要寫入 `state.session`。

### B2. 詳解提到選項字母，但選項會被打亂
q72 的詳解寫「Option C reverses the meaning」與「C 顛倒意義」。但 `makeSession` 每次都會重新排列選項順序，畫面上的 C 幾乎不會是原本那個選項。
**建議**：改成描述內容，例如「『0 表示相同、1 表示正交』把意義顛倒了」。我用 grep 搜過，全庫只有這一題有這個問題。之後新增題目時，`validate.mjs` 可以加一條規則，禁止詳解出現 `Option [A-D]` 或單獨的字母代號。

### B3. 鍵盤作答流程會中斷
1. **按 Enter 送出的是先前選的答案**：先按 `1` 選了 A，再用 Tab 移到選項 C 按 Enter。keydown 的判斷（app.js:63）會阻止預設行為，然後 `submit()` 送出 A，而不是選取 C。**建議**：焦點在 `.option` 上按 Enter 時，應該選取該選項；只有焦點在選項上、且就是目前已選的那一個，或焦點在「確認答案」按鈕上時，才送出。
2. **送出後焦點遺失**：`render()` 用 `innerHTML` 重建整個畫面，焦點會回到 `body`，鍵盤使用者要 Tab 穿過整個側欄才能按到「下一題」。答題後選項變成 `disabled`，也會被移出 Tab 順序。**建議**：送出後把焦點移到詳解區的標題，或直接移到「下一題」按鈕；作答後允許按 Enter 或 → 進下一題，並讓提示文字同步說明。切換收藏、切換語言之後，也要把焦點還原到原本的按鈕。

### B4. 作答後，螢幕閱讀器讀不到哪個是正確答案
選項按鈕的 `aria-label` 會覆蓋可見文字，所以「✓ 正確答案」「× 你的答案」不會被讀出來。`announce()` 只說「正確答案與詳解已顯示」，沒有說是哪一個。
**建議**：在 aria-label 後面加上結果文字（例如「，正確答案」），或乾脆移除 aria-label，讓可見文字成為名稱；announce 也加上「正確答案是 B：⋯」。

## 2. 來源與圖片呈現（對應使用者「詳解要附圖片與來源」的要求）

有幾題的來源是逐字稿，但 `note` 已經指出對應的講義頁，而那些頁面的圖片都已經轉好了。依使用者的要求，這些題目應該附上圖：

附圖前請逐張打開確認內容。「逐字稿為主、投影片為輔」的題目，也可以額外加一個 `slidePage` 欄位，讓來源同時顯示兩者。

### S2. q98 附錯頁
詳解的關鍵句是「locality of reference 是主要原因」，出自 **p.46**，但附的圖是 p.45。p.45 只有「up to 50x faster」，沒有主要原因，我已開圖確認。**改附 `lecture-4-p46.webp`。**
其他跨頁的 locator（q37、q38 的 pp.31,33；q75；q77；q98）目前只會顯示第一頁。至少要確保附的是**含關鍵句的那一頁**。

### S3. 來源文字太小，而且是內部路徑
- `.source-citation p` 是 11px 灰字，`.source-label` 是 10px。來源正是使用者要求的重點，現在卻是全頁最難讀的區塊。中文在 10–11px 很吃力。**建議**：內文至少 13px，檔名至少 12px。
- 畫面上直接顯示 `materials/transcripts/逐字稿_341595 (已AI校正).txt`，這是本機路徑，學生在網站上打不開。**建議**：在 `source-map` 加一組對照，顯示成「第 X 堂逐字稿（341595）· [21:18.7]」或「講義 4《Preprocessing and Representation》p.17」。
- `note` 內有面向編者的文字，例如 q4 的「mirrors the user's exam note」、q85 的「definition enriched from」。學生看不懂，請改成中性的說法，例如「對應課堂考點筆記 15:38」。

### S4. 雙語模式下英文詳解被弱化
正式考試是英文閉卷，但 `.explanation-en` 是 12px 灰字，排在 13px 的中文詳解之後。**建議**：英文詳解至少與中文同字級、同顏色。

## 3. 次要但值得修

- **字級過小的狀態文字**：`.legend` 9px、題號格 9–10px（≤1150px 時）、`.keyboard-hint` 和 `.navigator .note` 10px、`.footer` 10px。建議下限是 11px，中文內容下限 12px。
- **「練習這 N 題」數字不一致**：按鈕的 N 不考慮搜尋字詞和狀態篩選（`bankPage` 的 pool），但下方列表有考慮，兩邊數字會對不上，實際開始的題目也和看到的不一樣。建議讓兩者使用同一個 `filteredBank(mode)`。另外，搜尋時只更新列表、不更新按鈕上的數字。
- **計時器會累積離開的時間**：`formatElapsed` 用的是牆上時間，隔天回來繼續練習，計時會變成「1440:00」。如果不打算只計算作答時間，建議改標成「開始於⋯」，或在超過 99 分鐘後不再顯示。
- **重新整理到 `#results` 的情況**：如果當下的練習還沒結束，結果頁會把它當成已結束來顯示 0 分。建議 `session` 尚未結束時導回 `study`。
- **q17**：「odd k helps avoid ties」只適用於二元分類，建議加上「in two-class problems」。
- **q99**：「the slides themselves give prompts in both English and Chinese」，但來源是逐字稿，這句沒有被引用的頁面支持。請補上頁碼，或刪掉這句。
- **題庫改版後的舊紀錄**：q69/q70 換題以後，`localStorage` 中這兩題舊的 `history` 和 `answers` 仍然有效，但對應的已經是不同的選項。還沒上線所以影響不大；長期來說，建議在 state 裡存一個題庫版本（或雜湊值），內容不一致時清掉受影響題目的紀錄。

## 4. 不建議做的事（範圍控制）

不需要新增帳號、雲端同步、計時考試模式、問答題批改或更多題目。上面的修正都能在現有架構內完成。

## 5. 摘要：最重要的 6 項

1. **B1**：開始新練習或在題庫點單題時，未完成的練習會被無聲覆蓋。加確認；點單題改成不寫入 session 的預覽。
2. **B2**：q72 詳解寫「Option C／C 顛倒」，但選項會打亂。改成描述內容，並在驗證腳本加規則。
3. **B3**：按 Enter 會送出先前選的答案；送出後焦點遺失，選項 disabled 後也無法 Tab 回去看。
4. **B4**：選項的 aria-label 讀不出正確或錯誤，announce 也沒說正確答案是哪一個。
5. **S1/S2**：q8、q33、q39、q52、q55、q56、q58 有現成講義圖卻沒附；q98 附錯頁（p.45 應改為 p.46）。
6. **S3/S4**：來源區只有 10–11px，顯示本機路徑和編者用語；英文詳解被弱化。字級提高到 ≥12–13px，並改成人看得懂的來源標籤。
