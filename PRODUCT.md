# Recall Lab

## Register

product

## Users

TMU machine learning students preparing for the English midterm on 2026-11-04. Traditional Chinese explanations support English exam literacy.

## Product Purpose

100 source-traceable bilingual multiple choice questions; full-bank practice, random quizzes, immediate feedback, wrong-answer review, local progress. Success means students can explain their mistakes and return to the course source.

## Brand Personality

Precise, confident, energetic. User explicitly delegates visual decisions to Codex and Claude Opus, using an Awwwards reference.

## Anti-references

Avoid generic learning management dashboards, repetitive icon cards, distracting motion while answering, and answer explanations without evidence.

## Design Principles

- Start studying in one action.
- English questions first, Chinese support available.
- Explain the reasoning and show the source, including slide images when available.
- Make unanswered, incorrect, and correct states distinct with text as well as color.
- Store progress locally, no account required.

## Accessibility & Inclusion

Keyboard operation, visible focus, readable contrast, reduced motion, responsive layouts, explicit labels and non-color status indicators. Aim for WCAG AA; no certification claimed.

## Confirmed copy preference

User requested plain, direct functional labels; remove motivational slogans and AI-sounding marketing copy throughout. Keep the visual design.
